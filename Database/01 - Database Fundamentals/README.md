# Database Fundamentals

This folder contains the supporting materials for the **Database Fundamentals** video from the Database playlist.

In this lesson, we introduce the fundamental concepts behind databases before moving into practical SQL and PostgreSQL.

## Topics Covered

* What is a Database?
* Why Digital Databases Matter
* Database Management Systems (DBMS)
* How Applications Interact with a DBMS
* CRUD Operations

  * Create
  * Read
  * Update
  * Delete
* Relational Databases
* Non-Relational Databases (NoSQL)
* Tables, Rows, and Columns
* Primary Keys
* Foreign Keys
* Relational Database Management Systems (RDBMS)
* SQL — Structured Query Language
* NoSQL Database Models
* Database Queries

## Materials

This directory may include:

* `slides/` — Presentation slides used in the video
* `code/` — Code and SQL examples
* `datasets/` — Datasets used in the lesson
* `resources/` — Additional supporting materials

## Goal

By the end of this lesson, you should have a basic understanding of how databases work, how data can be organized and managed, and how SQL fits into the relational database ecosystem.

This foundation will help us move into the practical part of the course, where we'll start working with PostgreSQL, creating databases and tables, and writing SQL queries.
