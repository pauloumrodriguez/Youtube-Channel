# Database

This directory contains the supporting materials for the **Database** playlist on my YouTube channel.

The playlist starts with the fundamentals and gradually moves into practical database development using SQL and PostgreSQL.

## Topics

Throughout the playlist, we'll explore topics such as:

* Database Fundamentals
* Relational Databases
* Non-Relational Databases
* SQL
* PostgreSQL
* Tables and Relationships
* SQL Queries
* Database Schemas
* Database Design
